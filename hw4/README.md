# Домашнее задание №4. Требования и архитектурное мышление

Проект централизованной платформы уведомлений онлайн-банка. Каналы доставки — push, SMS и email.

## Содержание

- [Требования](requirements.md) — задания 1–7.
- [RFC](RFC-001.md) — задание 8: два варианта критичной доставки, расчёты нагрузки, обоснование выбора и ограничения.
- [Диаграммы](diagrams/) — C4 Container, основной сценарий и failover для каждого варианта. Исходники — PlantUML (`.puml`), изображения — SVG (`.svg`).

## Просмотр работы

Текстовые документы открываются на GitHub или в редакторе с предпросмотром Markdown. Диаграммы SVG открываются в браузере. Для просмотра готовых файлов установка зависимостей не требуется.

Из корня репозитория на macOS:

```bash
cd hw4
open -a TextEdit README.md requirements.md RFC-001.md
open diagrams/*.svg
```

TextEdit показывает исходный Markdown. Для форматированного просмотра используйте предпросмотр Markdown в редакторе.

## Локальный HTTP-сервер

При необходимости диаграммы можно просматривать через локальный сервер. Требуется Python 3. Команда выполняется из корня репозитория:

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory hw4
```

Откройте [каталог диаграмм](http://127.0.0.1:8000/diagrams/) и выберите SVG. Остановка сервера — `Ctrl+C`. Сервер раздаёт Markdown как файлы и не преобразует его в страницы.

Работа содержит архитектурные документы и диаграммы; отдельного приложения для запуска нет. Kafka, PostgreSQL и Temporal описаны в RFC как технологии проектируемой системы.
